# CoAI — AI Interview Assistant: Comprehensive Guide

Welcome to the comprehensive documentation for **CoAI — AI Interview Assistant**. This document unifies all project information, system architecture, database design, key features, and step-by-step running instructions.

---

## 1. Application Overview
**CoAI** is a MERN stack application designed to help candidates prepare for interviews by conducting intelligent, real-time mock interviews. It supports written (text) and verbal (voice-based) modes, parses candidate resumes to generate personalized questions, grades responses using LLMs, groups weaknesses into actionable categories, and presents progress on a dynamic dashboard.

### Core Stack
*   **Frontend:** React (Vite, React Router, Axios, Socket.io-client, Vanilla CSS)
*   **Backend:** Node.js, Express, Socket.io
*   **Database:** MongoDB Atlas (Mongoose ODM)
*   **AI Integration:** Google Gemini API with a robust fallback chain utilizing Groq Cloud (Llama 3.3, Llama 3.1, Mixtral, Gemma 2)

## 3. Data Models (Mongoose Schema)

### User Schema (`User.js`)
Stores user profiles and credentials. Password hashes are generated using `bcryptjs` (10 salt rounds).

### Interview Schema (`Interview.js`)
Tracks mock interview metadata, progress, overall scoring, and computed weaknesses:
*   `userId`: Reference to the `User` document.
*   `interviewType`: `'resume_based'`, `'hr'`, or `'company_specific'`.
*   `status`: `'planned'`, `'in_progress'`, `'completed'`, or `'terminated'`.
*   `overallScore`: Real-time score average calculated on completion (0-100).
*   `weakTopics`: Array of `{ topic: String, count: Number }` grouping topics with low scores or skips.

### Question Schema (`Question.js`)
Contains the specific questions generated for an interview, along with submitted answers and evaluations:
*   `interviewId`: Reference to the `Interview` document.
*   `question`: The question text generated by the AI.
*   `expectedConcepts`: Array of key topics/keywords required in a good answer.
*   `answer.candidateText`: The answer text submitted by the user.
*   `feedback`: Detailed grading feedback generated by the AI.
*   `score`: Question score (0-100). If the answer is off-topic or irrelevant, the score is set to `0`.

## 4. Key Workflows & Features

### A. Authentication & API Security
*   **Password Hashing:** Passwords hashed with `bcryptjs`.
*   **JWT Handshake:** Upon login, the backend issues a JSON Web Token containing the user's ID.
*   **Axios Request Interceptor:** Adds the token automatically into the HTTP `Authorization: Bearer <token>` header of every frontend request.
*   **Auth Middleware:** Authenticates Express requests using JWT token verification.

### B. High-Reliability AI Integration (Fallback Chain)
To prevent API limits (HTTP 429) from blocking users, the AI generator uses a fallback chain:
1.  **Google Gemini** (Primary model: `gemini-3.6-flash`).
2.  **Groq Llama 3.3** (`llama-3.3-70b-versatile`) if Gemini fails.
3.  **Groq Llama 3.1** (`llama-3.1-8b-instant`) if Llama 3.3 is rate-limited.
4.  **Groq Mixtral** (`mixtral-8x7b-32768`) and **Gemma 2** (`gemma2-9b-it`) as tertiary fail-safes.

### C. Live Answer Evaluation
*   Grades answers instantly in `submitAnswer`.
*   Compares the candidate's answer with `expectedConcepts` (key terms and context).
*   Applies a relevance check: off-topic, bypass attempts, or gibberish answers receive an immediate **score of 0**.
*   Generates a short, encouraging feedback summary (under 3 sentences).

### D. Smart Dashboard & Auto-Healing
*   **Auto-Healing:** If you finish answering all questions but close the window, loading the Dashboard automatically completes the interview, calculates final scores, and aggregates statistics.
*   **Normalized Weak Areas:** Subtopics are grouped using keyword matching into parent categories (e.g. `Java Collections` and `Java Exception Handling` are unified under **Java**).
*   **Customization Deletions:** Premium red delete buttons next to completed interviews and weak areas allow you to clean up your dashboard and customize your prep history.

## 5. Step-by-Step Running Guide

### Step 1: Clone and Configure Environment Variables
Create a `.env` file inside the `backend/` directory:

```env
PORT=5005
MONGO_URI=mongodb+srv://<username>:<password>@cluster.mongodb.net/coai
GROQ_API_KEY=gsk_your_groq_api_key_here
GEMINI_API_KEY=AQ.your_gemini_api_key_here
JWT_SECRET=your_jwt_secret_key_here
```

### Step 2: Install Dependencies & Run Backend
Open a terminal in the `backend/` folder:
```bash
# Install packages
npm install

# Start backend server
node server.js
```
*The backend server will run on `http://localhost:5005`.*

### Step 3: Install Dependencies & Run Frontend
Open a separate terminal in the `frontend/` folder:
```bash
# Install packages
npm install

# Start Vite development server
npm run dev
```
*The frontend application will compile and start on `http://localhost:5173`.*

## 6. Verifying the Setup
1.  Open your browser and navigate to `http://localhost:5173`.
2.  Create a user account on the Registration page and log in.
3.  Upload a PDF resume to populate your profile.
4.  Go to **Start Interview** and pick **Resume-Based** or **HR / Behavioral**.
5.  Answer the questions in the mock room. You will see the progress bar and questions sidebar update in real-time.
6.  Upon completion (or manually ending), check the **Dashboard** to see your updated overall performance, recent activities, and weak areas categorized by programming language or topic!
